# 本回合 Stage 入场与区域限制验证

## 本轮结论

修正新建对局中“入场限制锁在旧区域，而未锁住实际新区域”的问题。
不新增技能登记，不提升人工审核状态；登记数仍为 **899 / 1212（74.17%）**、manual **313**。
本轮是 `member-entry-current-area-history` 子任务，不代表通用效果替换登场的父任务已完成。

## 已复现的错误

设 A 为本回合新登场的 Member，B 为此前已在 Stage 的 Member：

| 时点 | 左 | 中 | 右 | 后续 Member 的合法登场区域 |
|---|---|---|---|---|
| A 登场后 | A（本回合） | B（此前） | 空 | 中、右 |
| A 与 B 位置交换后 | B（此前） | A（本回合） | 空 | **左、右** |
| 修正前错误结果 | B（此前） | A（本回合） | 空 | 错误地允许中、右 |

先以普通登场和 Baton Touch 两种入口各增加一个失败测试，均复现了上述相反结果。
修正后相同测试通过：中区域的非法操作拒绝且不支付 Energy；左区域允许对原 B 正常替换或 Baton。

## 实现与兼容边界

- 新建对局保存 `member_card_instance_ids_entered_stage_this_turn`，记录 Member 卡的身份。
  判断区域时，检查该区域当前顶部和所有下方卡，不要求历史区域标记跟随交换。
- 普通登场、单人 / 双方效果登场、手动从外部入场、从手牌 / 控室放入下方以及
  Baton 被替换卡从控室回到下方，均登记实际外部入场。
- Position / Formation / Stage 内手动移动和附属卡在 Stage 内转移，不凭空新增外部入场记录。
  附属 Energy 不进入 Member 入场记录。
- Member 卡离开 Stage 后，旧区域不会继续被错误锁住；身份记录保留到回合结束，
  但只有当前仍在区域内的卡会影响区域选择。
- 旧快照缺省为 `None`，继续使用旧区域历史；序列化时省略此字段。
  旧 Replay 的动作解释、JSON 结构与 canonical hash 不因新增空字段而改变。
- 新回合清空新模式的身份列表，旧模式仍为 `None`，不在读档或回合转换时悄悄升级旧对局。
- 对手的序列化视图不包含这项内部历史；AI / API Play 输入按既有只读视角构造，不增加私有身份数据。
- 不修改 Card Schema、runtime SQLite schema、decklist 或现有开局请求格式。

## 专项验收

当前新增 **37 项**专项测试；均为确定性断言，不代表完整人工规则裁定：

| 场景 | 验证内容 |
|---|---|
| 普通 / Baton 入场后交换 | 限制跟随 A；旧 B 所在区域可再登场；非法位置拒绝且状态不变 |
| 六种阵型排列 | 每次只按 A 的当前位置禁止区域；移动不增加入场历史；序列化后合法区域一致 |
| 手动外部入场与 Stage 内移动 | 手牌 / 控室进入左、右区域都会记录；Stage 内再移动不重复记录 |
| 新 / 旧附属 Member 随组移动 | 本回合外部放入下方的 Member 会限制当前组；上回合已存在的附属卡不被误记 |
| 附属卡在 Stage 内转为顶部 | 保留原来的外部入场身份，不把 Stage 内移动记录为新的外部入场 |
| Member / Energy 结构化附属处理 | Member 手牌费用、Member 控室目标和 Energy 费用分别验证，不混淆对象 |
| 单人 / 双方效果登场 | 控室进入 Stage 登记所属玩家的身份，Stage 内转移不新增；双方的选择互不混写 |
| Baton 被替换卡作为附属回场 | 从控室返回 Stage 下方会登记；不重复收取登场费用 |
| 新旧 Replay | 每一步 state hash 一致；实际 runtime SQLite 导出 / 重放保留各自语义 |
| 回合重置与非法批次 | 新列表归零、旧模式不升级；后续步骤失败时，前一步新增的身份和区域变化整体回滚 |
| API / AI / 隐藏信息 | 旧开局请求无需新参数；三种 AI 提交合法区域；更换对手隐藏手牌不影响决策；对手看不到内部历史 |

既有 Baton 自动恢复 Energy 的测试曾只清空旧区域标记来模拟“此前已在场”的 Member。
已同步清空该夹具的新历史；未删除测试、跳过断言或放宽引擎规则。
完整工程检查由 `check --profiles control registry backend web` 绑定源码指纹保存。

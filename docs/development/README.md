早期 unresolved/probe 与后续正式验证并存时，必须结合精确卡号、原文版本、registry 和最终验收判断取代范围。
同一主题优先续写既有报告，避免每轮再建摘要文件。原路径保留，ignored 日志仅在保存证据的本机可用。

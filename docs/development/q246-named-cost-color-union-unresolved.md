# Q246 指定名称费用的颜色并集边界

官方卡表的 [Q246](https://llofficial-cardgame.com/cardlist/searchresults/?cardno=LL-bp6-001-R%EF%BC%8B&faq=) 直接针对 `LL-bp6-001:2`：示例中两张弃牌的基本 Heart 有一个共享颜色，结果对四种不同颜色各获得一颗。该示例证明共享基本颜色不重复增加；不单凭该问答推断 Blade Heart、空费用或完整卡名匹配规则。卡片完整双段 revision59、SHA256 `cf58746e81720b3db7a0dc378b36dd4b8fb60e88c63ab1a9d97ef0ebd5691331`；第二段仍 manual，第一段可执行登记不变。

本审计仅构造未登记测试快照，将手牌中三个指定名称的零至四张作为已选费用；上限四及测试卡都是夹具，不是本卡的费用上限或完整对局。双方实际支付、零至四张及重复名称实体、非法选择原子拒绝和 SQL Replay 被核对。选择两张具有四种基本颜色且共享一个颜色的合成卡时，既有 `gain_heart_from_selected_card_colors` 对共享颜色分别产生两个补正，而不是 Q246 示例的一次；该操作按原有逐卡语义运行，不称既有正式卡有本卡错误。现有精确名称筛选不会拆分三人组合名称，这只是当前实现，不代表官方名称规则。

Q246 已消除示例中的基本颜色去重疑点，但可选发动与零枚费用、完整名称资格、Blade Heart、来源对象及完整性仍须单独验证；不可直接绑定旧颜色操作、改变旧 Replay 或解除其他 blocked。双方私有候选投影及 SQL 证据见 ignored 验收；此前四 AI 的正式 manual 拒绝是上一审计的独立证据，不算本轮新 AI 测试。应用、卡库、登记、SQL schema 和默认 AI 未改，完整门禁与提交状态以验收记录为准。

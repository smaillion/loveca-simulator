# 私有名称任意张弃牌原型

新增仅允许 `UNREGISTERED-` 固定快照使用的 `private_partial_names_unlimited_discard_v1`。Live 开始时，该测试形状可选从本人手牌选择零至全部候选并实际弃牌，随后抽一张；候选按固定三个引号名称与归一化卡名的部分匹配筛选。上限是当前实际候选数量，而非固定三张或假设牌组上限。选择策略、费用、抽牌动作、触发与使用者被静态限制；非法候选、重复 ID、错误角色和额外参数原子拒绝。

固定综合规则 1.06 第 2.3.2.1–2.3.2.2 节及其 PDF 哈希见 [三人曜卡审计](./ll-bp2-composite-cost-unresolved.md)。该原型只验证名称和私有动态费用，并不模拟该正式卡的 Blade、原来源对象或整卡语义；`LL-bp2-001:3` 及其他正式登记不绑定新策略，已复现问题尚未修复。旧名称筛选、旧 JSON/Replay、卡库与 SQL schema 不变，其他 blocked 不恢复。

双方真实 Live 开始、零至六张及非法费用、受控来源移入未知库、玩家近期事件与 provider 构造隐私、四 AI 和 UI 的范围及实际门禁见 ignored 验收。CONTROL 与构造卡是测试夹具，provider 未联网，不称完整对局、随机正条件或策略改善。

# 非空手全部弃牌抽六未登记原型

新增 `private_all_hand_nonempty_v1`：仅允许固定 `UNREGISTERED-` 登场快照，费用为弃置当前本人全部非空手牌，之后抽六；选牌上下限随当前手牌数量变化，服务端要求选中实体集合与当前手牌完全一致。部分、重复、其他玩家、错误角色、额外字段及辞退时附选牌均原子拒绝。空手时该受限快照不入待机，不裁定正式能力空手能否支付。旧选择策略、旧 JSON 与 Replay 保留。

双方受控登场后的 1、2、3、4、6 张手牌、非空辞退、非法输入、来源移入手牌或未知牌库、当前手牌变化和短库执行均经测试；34 份新 SQL Replay 保存于 ignored 验收目录。四 AI 在双方四张手牌构造状态均实际提交全部四张；对手隐藏身份替换不改变动作或输入。双方玩家含费用/抽牌的近期事件、短库刷新后重入隐藏手牌以及来源入未知库的投影和 API-play/agent provider 构造隐私经测试，provider 未联网；CONTROL 与构造状态不是完整对局或自然中断。界面仅验证 1 和 4 张完整选择，不称人工完整对局。

这不是 `PL!SP-bp7-011:1` 的正式实现：该卡仍 manual，空手支付、抽六刷新及完整逐卡语义仍需官方依据与独立验证。未改卡库、registry、SQL schema、默认 AI 或其他 blocked。旧固定上限缺口见[先前审计](./tomari-all-hand-fixed-cost-gap.md)；同 30 牌组冻结、全部门禁与提交状态以 ignored 验收记录为准，不称随机正条件或策略改善。
